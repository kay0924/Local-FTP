Folder Access

Tick the folders each person can open. Everything else stays hidden from them. Admins always see everything.

How it works. A ticked box lets that user see and open the folder (and everything inside it) when they log in. All folders gives access to everything, including folders created later. What a user may do inside (upload, delete, rename…) is still set per user in Settings → User Management. Click a folder name to highlight who has access. Users marked custom have hand-written rules — saving them replaces those rules.
